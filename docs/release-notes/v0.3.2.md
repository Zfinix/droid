# Droid 0.3.2

*Your phone. Any agent.*

Experimental. Android 8 or later, 64-bit ARM (`arm64-v8a`) only. Fewer steps from download to a first task, and the agent asks before risky actions on every chat app.

---

## Update

On the phone, open [droid.withaster.dev/download](https://droid.withaster.dev/download), or download `droid.apk` from the [assets below](#assets), and open it. From a computer:

```sh
adb install -r droid.apk
```

It installs over 0.3.1 and keeps your settings, keys, sessions and memory.

## Easier to start

- **Three steps to a first task.** Onboarding is now a model, Screen access, then Start. The free models are the big button, the chat in the app is the default, and where to talk is one row you can change later. Notifications are asked for on your first message, not on the welcome screen.
- **One download link.** [droid.withaster.dev/download](https://droid.withaster.dev/download) always gets the newest `droid.apk`. Releases no longer carry the `.aab`, which a phone cannot install.
- **Requirements up front.** The README says what Droid needs before you download: Android 8 or later on 64-bit ARM, and no iPhone. It also walks through the install warnings: allowing your browser to install, Play Protect's **Install anyway**, and **Allow restricted settings** on Android 13 and later.
- **Setup links from the website.** [droid.withaster.dev/setup](https://droid.withaster.dev/setup) makes a link or QR code with the model, its key and the chat app, so nothing is typed on the phone.
- **Fewer permissions.** Droid no longer asks for access it does not use, such as SMS and call logs.
- **Plain error messages.** A key that is turned down, a busy free tier or a lost connection now reads as one plain sentence, with the raw error kept in the log.
- **Pair a computer with nothing to paste.** Over USB, `npx -y @withaster/droid pair --adb` reads the keys from the phone itself. **Let computers in** under Connect a computer turns on both in one tap.
- **Restricted settings, explained.** When Android greys out the Screen switch, Droid shows the one extra step and a button straight to App info.
- **Somewhere to start.** An empty chat offers three example tasks to tap.
- **Version in Settings.** Settings shows which Droid you run, and tells you when a newer one is out.

## Safer

- **Approvals on every chat app.** Telegram, WhatsApp and iMessage now run in `auto` mode, like the chat in the app: the agent asks before risky actions and waits. Telegram shows buttons; WhatsApp and iMessage end with "Reply yes, always, or no."

## Fixes

- **Full approvals in the app.** A long approval card now opens to show the whole request before you answer.
- **Phones Droid cannot run on are told so.** A 32-bit or x86 phone now hears that it is not supported, instead of being told to reinstall.
- **Starts after a reboot.** The agent comes back on its own after the phone restarts, with no need to open the app.

## Known limits

- Aster Relay is still coming soon. USB, Wi-Fi and Tailscale work today, and so does a relay you host yourself.
- Text input into views without an input connection, and PIN and pattern locks, are as before.
- Found a bug? [Open an issue](https://github.com/Zfinix/droid/issues).
